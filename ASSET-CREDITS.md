# Midnight Manor — artwork and dependency credits

Midnight Manor combines project-created graphics with explicitly reused, licensed artwork. The artwork is not all newly authored here.

## Active imported artwork

The current renderer uses LPC wooden furniture, upholstery, containers, house interiors, animated doors, floors and walls. Creator names, upstream URLs, component credit files, selected licenses, source archives and modification descriptions are preserved in [public/assets/lpc/CREDITS.md](public/assets/lpc/CREDITS.md). That file and its referenced notices are part of the distribution. Some artwork has attribution and share-alike terms; it must not be relabelled as wholly original or proprietary art. The packed material sheet and runtime recolors retain their component provenance.

The full asset-specific notices and license texts remain beside the artwork, including CC-BY-SA 3.0, CC-BY-SA 4.0 and CC-BY 4.0 notices as documented per component. These notices describe artwork, not an automatic license assignment to this game's source code.

## Retained fallback artwork

Kenney Roguelike Indoor pack, by Kenney Vleugels / Kenney: https://kenney.nl and https://opengameart.org/content/roguelike-indoor-pack . The transparent atlas and CC0 notice remain in public/assets/kenney/. It is used by the retained modular furniture fallback.

## Project-created work and references

The mansion layout, procedural character sprites and class outfits, interface, interaction indicators, generated audio, gameplay overlays and new Midnight Manor home illustration are project-created. Imported furniture and materials are credited separately above. Earlier procedural furniture renderers are retained where the active renderer still imports them as fallbacks.

Pokemon, Among Us and Propnight were gameplay/presentation references. No proprietary sprites, maps, ROM data or artwork from those games have been included. Features with similar concepts are not claims that those games' code was authored here.

## Libraries and project origin

Phaser, Socket.IO, PathFinding.js and Vite remain third-party dependencies. Preserve their licenses and transitive dependency notices. The hunt-only package includes THIRD-PARTY-NOTICES.txt generated from installed dependency notice files. Dependency notices are included in THIRD-PARTY-NOTICES.txt.
